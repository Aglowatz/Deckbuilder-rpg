# Reader's brief: dialogue sample

You are a reader with no background on this project. Please do not open any other file in this repository; read only
`docs/review/dialogue_nov13/round2/sample.md`.

The sample holds 40 short conversations from a fantasy role-playing game with a card-battle system, set in a kingdom called Patchwork.
Each conversation is shown in two versions, A and B. You are not told anything about where the versions came from, and which letter is
which changes from one conversation to the next. Judge each version only by what is on the page.

## What to do
For every conversation, score Version A and Version B separately, from 1 (poor) to 10 (excellent), on:
1. **Naturalness:** does it sound like a person talking?
2. **Voice:** could you tell who is speaking without the name? Does this speaker sound unlike the others in the sample?
3. **Emotional impact:** do you feel anything?
4. **Clarity:** if the lines tell the player to do something or go somewhere, is it clear what and where? (Score 5 if the lines carry no
   instruction.)
5. **Humour:** where the lines try to be funny, does it land? (Score 5 if they are not trying to be.)

Then:
- say which version of each conversation you prefer, A or B, in one short sentence of why;
- list the **10 weakest individual lines in the whole sample**, quoting each exactly and saying which conversation and version it is in,
  with one sentence on what is wrong with it;
- list anything that confused you (a contradiction, an instruction you could not follow, a joke you did not understand).

## How to answer
Reply with:
1. a table with one row per conversation: number, A's five scores, B's five scores, preferred version, reason;
2. the 10 weakest lines;
3. the confusions;
4. three sentences on the overall difference you see between the versions you preferred and the ones you did not.

Be honest and specific. Do not try to guess which version is "the new one".
