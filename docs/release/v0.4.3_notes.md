# The Wayward Path v0.4.3 - stability hotfix (2026-10-21)

**Fixed: the freeze when first entering Crosspath after the cave, and the crash with the default graphics settings on laptops.**

Windows build: `builds/TheWaywardPath-v0.4.3-windows.zip` (SIZE). Unzip the whole folder somewhere you can write to (Desktop or
Documents) and run `TheWaywardPath.exe`. **Your saves carry over** from v0.4.0, v0.4.1 and v0.4.2 - including a save made right where
the game froze: choose Continue and Elder Maren's welcome plays again.

Start with `README_PLAYTEST.txt` in the folder.

## The Crosspath freeze

- Crosspath is now built a piece at a time behind a loading screen (it used to be built in one go on a black screen, 8-25 seconds
  without a single frame - longer on a laptop), and the loading screen stays up until the town draws smoothly.
- Whatever waits for you on arrival opens **one at a time**: level-ups, then reward boxes and quest notices, then the "too many Paths"
  warning, then Elder Maren's welcome. You can always move once the last one closes; if the Wanderer is ever held with nothing on screen,
  the game frees them within a few seconds.
- **Esc and F8 always work** - during loading screens, dialogue and arrival screens. Esc pressed while loading opens the pause menu as
  soon as the loading screen goes.
- A loading screen can no longer hang: if loading stops making progress, the game shows the area anyway and notes it in the log.

## The graphics crash on laptops

- On DirectX 12 the engine reports built-in laptop graphics (Intel Iris Xe, Intel Arc 130V, AMD Radeon Graphics) as a separate graphics
  card, so the game started them on **High** - the heaviest settings. The game now recognises built-in graphics by name and starts them
  on **Medium** (older Intel UHD graphics on **Low**). If you were on High from an earlier version on built-in graphics, you are moved to
  the recommended level once; you can raise it again in Settings.
- On Intel built-in graphics, volumetric fog, ambient occlusion and MSAA stay off even on High (the effects most likely to crash there).
- **Crash-safe start:** if the game did not start or load properly last time, it starts in **Safe Mode** (Low graphics, heavy effects
  off) and says so on the title screen. If that happens twice in a row, it also switches to the other graphics driver (Vulkan or
  DirectX 12) by itself.
- Shaders are prepared at build time now, so the first launch spends less time compiling them.

## New in the folder

- `Start (Safe Mode).bat` - Low graphics with the heavy effects off. Try this first if the game crashes or freezes.
- `Start (Vulkan).bat` - the Vulkan renderer instead of DirectX 12. Try this if Safe Mode did not help.
- `Start (DirectX 12).bat` - DirectX 12, the normal renderer.
- `Start (Verbose Log).bat` - a much more detailed log, only when we ask for it.
- `README_PLAYTEST.txt` - how to start, what the start files do, where the logs are and what to send back.

## Reporting problems

- **F8** makes a report folder (screenshot, save, logs) at `%APPDATA%\Deckbuilder-RPG\feedback\`.
- If the game froze or crashed, please send `%APPDATA%\Deckbuilder-RPG\logs\wayward.log` (and `wayward.1.log`, the run before). The
  game now writes what it is doing to this log as it goes - it says exactly where the game stopped.
