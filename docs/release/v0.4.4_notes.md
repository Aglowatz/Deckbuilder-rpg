# The Wayward Path v0.4.4 - playtest build (2026-10-21)

**This build has the fixes for the Crosspath freeze and the graphics crash on laptops, and a polish pass over the game's dialogue.**

Windows build: `builds/TheWaywardPath-v0.4.4-windows.zip` (637 MB). Unzip the whole folder somewhere you can write to (Desktop or
Documents, not Program Files) and run `TheWaywardPath.exe`. If Windows says "Windows protected your PC", click "More info", then
"Run anyway".

**Your saves carry over** from v0.4.0 to v0.4.3, including a save made right where the game froze: choose Continue and Elder Maren's
welcome plays again.

Start with `README_PLAYTEST.txt` in the folder.

## The Crosspath freeze is fixed

- The first trip out of the cave into Crosspath could freeze on a black screen ("Not Responding") for a long time, or for good.
  Crosspath is now built a piece at a time behind a loading screen, and the loading screen stays up until the town draws smoothly.
  The first visit still takes a few seconds - that is normal.
- What waits for you on arrival opens **one at a time**: level-ups, then reward boxes and quest notices, then the "too many Paths"
  warning, then Elder Maren's welcome. You can always walk once the last one closes.
- **Esc and F8 always work**, also during loading screens, dialogue and arrival screens.
- A loading screen can no longer hang: if loading stops making progress, the game shows the area anyway.
- The window keeps answering Windows while an area is being built, so it is no longer greyed out as "Not Responding" on slower PCs.

## The graphics crash on laptops is fixed

- Laptops with built-in graphics (Intel Iris Xe, Intel Arc, AMD Radeon Graphics) were started on **High**, the heaviest settings, and
  could crash. They now start on **Medium** (older Intel UHD graphics on **Low**). If you were moved to High by an earlier version, the
  game puts you on the recommended level once; you can raise it again in Settings.
- On Intel built-in graphics, volumetric fog, ambient occlusion and MSAA stay off even on High.
- Shaders are prepared when the game is built, so the first start spends less time on them.
- Long sessions use less graphics memory, and a broken picture in the Verdant Dump with Vulkan is fixed.

## Safe Mode and the start files

If the game did not start or load properly last time, the next start is in **Safe Mode** (Low graphics, heavy effects off) and the
title screen says so. If that happens twice in a row, the game also switches to the other graphics driver by itself.

Next to the game are five start files. If the game crashes or freezes, try them in this order:

- `Start (Safe Mode).bat` - Low graphics with the heavy effects off. Try this first.
- `Start (Vulkan).bat` - the Vulkan renderer instead of DirectX 12, if Safe Mode did not help.
- `Start (Compatibility).bat` - a last resort for older graphics chips (simpler, plainer, slower to load).
- `Start (DirectX 12).bat` - DirectX 12, what the normal start uses.
- `Start (Verbose Log).bat` - a much more detailed log, only when we ask for it.

## Reporting a problem

- Press **F8** at any time - it works on every screen, even during loading or dialogue. Write what happened and press Send. This makes
  a report folder (screenshot, your save and the game's logs) in `%APPDATA%\Deckbuilder-RPG\feedback\`.
- If the game froze or crashed and F8 was not possible, please send `%APPDATA%\Deckbuilder-RPG\logs\wayward.log` (this run) and
  `wayward.1.log` (the run before). The game writes what it is doing to this log as it goes, so it says where it stopped. Copy them
  right away, before starting the game again more than once.
- Paste `%APPDATA%\Deckbuilder-RPG` into the address bar of a File Explorer window and press Enter to get there.

## Dialogue polish

- About 460 lines across the whole game were rewritten: the opening forest and Crosspath, all four zones, the Capital, the side
  dungeons, the Lab, the Old Well, townsfolk chatter and the loading tips. Characters sound more like themselves, jokes land cleaner,
  and running jokes now come back where they should.
- Every new line was checked to fit its dialogue box.

## Also in this build

- Fixed a rare error when a zone's title card was still on screen as you left the area.
