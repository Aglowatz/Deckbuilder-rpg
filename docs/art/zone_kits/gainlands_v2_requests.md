# Gainlands v2: art requests

Every STANDIN of the Gainlands v2 pass (`docs/art/gainlands_v2.md`) that should get painted art. Each row is one image, ready to paste into ChatGPT; the file name is what the importer expects in the Drive folder `Approved_ZoneKits/Gainlands` (then "import zone kit gainlands"). Until a file exists the stand-in in the game stays (built from the kit and primitives at the right scale).

**Style for every prompt (paste once at the top of each batch):**

> Painted 2.5D storybook style, matching the existing Gainlands kit (the House of Gains, the hamster-wheel mill, the red-and-gold banners): clean bold shapes, soft cel-shaded painting, warm bright midday light from the upper left, crisp soft shadows, rich but harmonious colours (sandstone tan #E0B880, brick red #D9483B, gold #F2C14E, cream #F7EBD3, iron #4A4A54, sky blue #5FA8D3). One object per image, centred, seen from the game camera (about 30 degrees above the horizon, front three-quarter view), on a fully transparent background (PNG with alpha), no ground shadow plate, no text, letters or numbers anywhere. Slightly oversized storybook proportions: a 1.7 m hero, doors 1.95 m, one storey about 2.5 m.

Scale notes give the in-game size, so the painter keeps proportions; the importer scales by the registry's `height`.
