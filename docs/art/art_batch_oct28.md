# Art batch Oct 28: the master missing-art catalogue

Written overnight Oct 27-28 from the art direction review (`docs/art/art_direction_oct28.md`) and the enemy roster review
(`docs/design/enemy_roster_oct28.md`). The catalogue itself is **`docs/art/art_batch_oct28.csv`** (one row per picture: Art ID, Category,
Zone, Name/What, Story/theme purpose, Where used, Stand-in today, Size/aspect + transparency, Destination Approved_* folder, File name to
save as, Priority, Image description, Notes); it is generated by `node tools/art_batch_oct28.js` from `tools/art_batch_oct28_rows.js`,
where every character's look is written once and shared by its portrait, sprite set, cut-out and Bestiary square. Nothing was generated
tonight; every row is a description.

Every ID below is accepted by an importer that exists today: cards by `import card art`, portraits / expressions / CUT-* cut-outs by
`import portraits`, SPR-* sets by `import npc sprites`, BST-* squares by `import bestiary`, icons by `import icons`, the hat sheet by
`import cosmetics`, STORY-* stills by `import key art`, zone pieces by `import zone kit <zone>` (new ids need a kit CSV row first).

## Style locks (paste once per ChatGPT session, then the row's description)

Each row's description starts with `[LOCK lock]` naming which of these to paste first. The texts are the sheet's own locks (NPC/Vendor
List, World Look Test, Card List, Icons, zone kits, Dungeon List) plus two new ones for the cut-outs and the story stills.

| Lock | For | Text |
|---|---|---|
| PORTRAIT | dialogue portraits and expressions | the NPC/Vendor List's Portrait Style Lock (2:3, waist up, transparent, 1024x1536) |
| CUTOUT | boss / lieutenant / gatekeeper entrance cut-outs | "Stylized fantasy character cut-out for a battle entrance card ... the SAME character as the dialogue portrait of the same NPC ... hips up ... entrance pose ... rim light in the Path colour ... transparent PNG, 2:3 1024x1536, top of the head about 6% from the top edge." (full text in the rows file) |
| SPRITE | world sprites (NPCs and roaming enemies) | the World Look Test's Sprite Style Lock + Sprite Strip Lock; the set rule (FRONT / SIDE / BACK idle + FRONT_TALK; walk sets add FRONTSIDE / BACKSIDE and a 4-frame WALK strip per direction) |
| BESTIARY | Bestiary squares | the Bestiary request list's lock (square, head and upper body, dark painted background) |
| CARD | card art | the Card List's style lock with the Path accents |
| STILL | story stills | "Stylized fantasy story illustration ... characters exactly as in their dialogue portraits ... lower quarter calmer ... 16:9 1792x1024" |
| BACKDROP | sky-transparent skyline strips | the World Look Test's Backdrop Style Lock (2048x1024) |
| CUTOUT_PROP / SHEET / TREE | zone props, decal sheets, trees | the zone kits' Cutout / Sheet / Tree locks |
| HAT | the Leaf Crown sheet | the cosmetics Hat Lock (five directions in a row, 2560x1024) |
| ICON | gear and feat icons | the Icons tab's lock with Path accents |

## Import commands (one Godot at a time, close between runs)

| Say | Run | Approve into |
|---|---|---|
| import portraits | `bash tools/import_portraits.sh` | `Approved_Characters` (NPC-ELDER*, every `NPC-*_EXPR`, every `CUT-*`) |
| import npc sprites | `bash tools/import_npc_sprites.sh` | `Approved_Sprites` (`SPR-ELDER-*`, `SPR-FOE-*-*`, `SPR-PRIMM-*`, `SPR-DUMPWORKER-*`); add a `NPC-FOE-<KEY>` row with the relative height to `data/source/npc_sprite_batch.csv` first, or the set is drawn at hero height |
| import bestiary | `bash tools/import_bestiary.sh` | `Approved_Bestiary` (`BST-*`) |
| import card art | `bash tools/import_art.sh` | `Approved` (`<Card ID>.png`) |
| import icons | `bash tools/import_icons.sh` | `Approved_Icons` (`ICON-GEAR-*`, `ICON-FEAT-*`) |
| import cosmetics | `bash tools/import_cosmetics.sh` | `Approved_Cosmetics` (`COS-HAT-LEAFCROWN-SHEET`) |
| import key art | `bash tools/import_key_art.sh` | `Approved_KeyArt` (`STORY-*`); then the one-line hook per still (see the row's Notes) |
| import zone kit `<zone>` | `bash tools/import_zone_kit.sh openingforest|gainlands|dna|buffet|heap|final` | `Approved_ZoneKits/<Zone>`; add the row to `data/source/<zone>_kit.csv` first |
| import env kit art | `bash tools/import_env_kit.sh` | `Approved_EnvKit` (the Crosspath pieces) |

then the Bestiary square: `Bestiary.cutout`); every `BST-*` square (the battle plate and the Collection Book; a square made under an
